# Starsector Mikohime OpenAL Addon

OpenAL add-on files for Mikohime, version 1.2.5.1.

Run `oalinst.exe` to install OpenAL. Run `Configure_Audio.bat` to open the bundled audio configuration utility.

## Downloads

Use the packaged ZIP from the repository's [Releases](../../releases) page. The release includes a SHA-256 checksum file for integrity verification.

Maintainers can publish a release by pushing a version tag such as `v1.2.5.1`.
